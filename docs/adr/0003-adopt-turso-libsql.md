# ADR 0003: Adopt Turso DB (libSQL) for Serverless Distributed Persistence

## Status
Accepted

## Context
The platform requires zero-cost, persistent storage that works without cold-start sleep delays, supports offline local development, and allows effortless bulk insertion of commands and modules generated by LLMs.

## Decision
Adopt **Turso DB** (libSQL Serverless) via `@libsql/client`. In local workstations and automated test runners, the system falls back to SQLite (`file:local.db` or `:memory:`).

## Consequences
- **Positive:** 9 GB storage and 1 billion reads/month on Turso free tier; instant connection without instance sleep; identical SQLite syntax across development and production.
- **Negative:** Requires network connection to Turso Cloud when using remote databases.
