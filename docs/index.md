# netdrill Documentation

Welcome to the engineering portal for `netdrill`, the universal stack-agnostic template for software development with autonomous AI coding agents.

- **[Architecture](ARCHITECTURE.md):** Open-canvas monorepo design, adaptive Makefile facade, and stack detection contracts.
- **[Development Guide](DEVELOPMENT.md):** Daily engineering workflows, Makefile targets, testing layers, and security hooks.

## Key Principles

- **Stack Independence:** Seamless support for any programming language or framework (C#, Java, Rust, Node, Python, Go, Elixir, etc.).
- **Rigorous TDD:** No production code without prior failing tests (*Red-Green-Refactor*).
- **Anti-Overengineering:** Guided by Ponytail principles and YAGNI.
- **Prior Visual Approval:** Mandatory interactive visual prototyping with OpenDesign before UI production code.
- **Zero Local Path Leaks:** Complete cross-machine portability with automated path linting.
