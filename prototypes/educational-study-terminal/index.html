Objetivo Técnico

Identificar processos com maior consumo de CPU e memória em modo detalhado

Comando fundamental para triagem de incidentes de lentidão em servidores web e bancos de dados.

🚨 Quando este comando salva sua pele em produção:

Cenário 1: Lentidão em Servidor de Aplicação

Usuários relatam timeout no checkout. O monitoramento indica 100% de CPU total. Você roda ps aux para ranquear qual worker está consumindo ciclos sem liberar threads.

Cenário 2: Processos Zumbis ou Deadlock

Um deploy recente falhou. Você precisa inspecionar a coluna STAT para verificar se há processos presos em D (I/O bloqueado) ou Z (defunct sem pai).

Cenário 3: Vazamento de Memória (Memory Leak)

O processo OOM-Killer está derrubando serviços auxiliares. O campo RSS revela a memória física real residente de cada PID, identificando o vazamento antes da máquina travar.

Dica de Linha de Comando

Para ordenar direto por CPU: ps aux --sort=-%cpu | head -n 10. Para consultar o manual completo: pressione M.

// GABARITO DE REFERÊNCIA Comando Único 
ps aux

a = processos de todos os usuários com terminal.
u = formato orientado ao usuário (CPU, MEM, USER).
x = inclui processos desacoplados do terminal (daemons).

ALERTA CRÍTICO
O que significa:

O processo está bloqueado no kernel aguardando o retorno de uma operação física de disco ou socket de rede.

Sinal Saudável (Baseline):

Transitório por alguns milissegundos. Processos normais ficam em 'S' (sleeping) ou 'R' (executando).

Sinal de Anomalia / Incidente:

Processos estagnados em 'D' por segundos causam Load Average explosivo e não respondem nem a 'kill -9'. Indica disco saturado ou NFS desconectado.

PS(1) Manual de Comandos do Usuário PS(1)
NOME

ps - exibe um instantâneo dos processos ativos no sistema.

SINOPSE

ps [opções]

DESCRIÇÃO

O ps exibe informações sobre uma seleção de processos ativos. Se você deseja uma atualização contínua em tempo real, use o top ou htop.

Esta versão do ps aceita vários tipos de sintaxe:
1. Opções UNIX padrão (precedidas por um único hífen, ex: -ef).
2. Opções BSD (sem hífen, ex: aux).
3. Opções longas GNU (precedidas por dois hifens, ex: --sort).

OPÇÕES FREQUENTES EM PRODUÇÃO

a - Lista processos de todos os usuários que possuem terminal associado.

u - Formato orientado ao usuário: detalha usuário dono, %CPU, %MEM, VSZ, RSS e horário de início.

x - Inclui processos que não possuem terminal associado (essencial para localizar daemons e containers em background).

--sort=-%cpu - Ordena a listagem pelo maior uso de CPU.

--sort=-%mem - Ordena a listagem pelo maior uso de memória RAM residente.

EXEMPLOS PRÁTICOS

ps aux | grep nginx - Localiza os workers e o processo master do Nginx.

ps -ef | grep postgres - Exibe a árvore completa com PPID do cluster PostgreSQL.
