Objetivo Técnico

Configurar política de firewall liberando tráfego LAN para WAN com NAT habilitado

Habilita saída de pacotes mascarando o endereço IP de origem da porta port2 para a porta port1.

▶ [STDOUT] Exemplo de Resposta do Ambiente (Terminal Output) Ctrl+O
Ocultar ▲
// Saída capturada ao rodar 'diagnose sys session list' / 'get' no FortiOS:
FW-DC-01 (policy) # get == [ 10 ] id: 10 name: LAN-Internet uuid: 9b128fa4-c819-5a12-87ba-1289fe4a1120 srcintf: port2 (192.168.10.0/24) dstintf: port1 (wan1 - 200.180.10.2) action: accept status: enable schedule: always service: ALL nat: enable (transip: 200.180.10.2:1024-65535) packets: 48,192 bytes: 14.8MB active-sessions: 124
// GABARITO DE REFERÊNCIA (11 linhas) FortiOS 7.x 
config firewall policy
    edit 10
        set name "LAN-Internet"
        set srcintf "port2"
        set dstintf "port1"
        set action accept
        set schedule "always"
        set service "ALL"
        set nat enable
    next
end
