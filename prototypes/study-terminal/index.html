Objetivo

Criar política de firewall liberando LAN para WAN com NAT ativo

Habilita o tráfego de saída mascarando o IP privado da porta port2 para a porta port1.

// Gabarito de Referência:
config firewall policy
    edit 10
        set name "LAN-Internet"
        set srcintf "port2"
        set dstintf "port1"
        set action accept
        set schedule "always"
        set service "ALL"
        set nat enable
    next
end
