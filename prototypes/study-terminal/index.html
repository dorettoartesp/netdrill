Objetivo Técnico

Configurar política de firewall liberando tráfego LAN para WAN com NAT habilitado

Habilita saída de pacotes mascarando o endereço IP de origem da porta port2 para a porta port1.

// GABARITO DE REFERÊNCIA (11 linhas) FortiOS 7.x 
config firewall policy
    edit 10
        set name "LAN-Internet"
        set srcintf "port2"
        set dstintf "port1"
        set action accept
        set schedule "always"
        set service "ALL"
        set nat enable
    next
end
