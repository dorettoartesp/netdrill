## Histórias de Usuário Atendidas
1. Como estudante, quero autenticar no sistema digitando apenas um PIN pessoal e pressionando Enter para começar a treinar sem burocracia de cadastro.
2. Como usuário móvel, quero campo de senha protegido e botão de acesso amplo com área de toque superior a 44px.

## Acessibilidade e Teclado
- Foco automático inicial no campo de PIN.
- Envio instantâneo ao pressionar tecla `Enter`.
- Estados de foco com anel visível e contraste WCAG AA.
