Procedure · Linux Administration Practice

Triage intermittent OOM in the service cgroup

The API is OOM-killed intermittently under load.

Goal: compare cgroup memory usage, limit and OOM events.

  1. Step 1 · Current usage $ cat /sys/fs/cgroup/system.slice/api.service/memory.current 
    1879048192

    Compare with memory.max in the next step.

  2. Step 2 · Limit $ cat /sys/fs/cgroup/system.slice/api.service/memory.max
  3. Step 3 · OOM events $ grep -E "^(oom|oom_kill) " memory.events

Commands used

cat grep
