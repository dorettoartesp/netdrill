Linux Administration Practice

ss

Socket inspection via Netlink, the modern netstat replacement.

ss [options] [filter]

Flags

FlagDescription
-t, --tcpTCP sockets only.
-l, --listeningListening sockets only.
-p, --processesShow owning PID and process (requires root).

Examples

Listening ports with process

$ ss -tulpn

-t TCP, -u UDP, -l listening only, -p process, -n no name resolution.

Netid State  Recv-Q Send-Q Local Address:Port
tcp   LISTEN 0      511    0.0.0.0:80

Use cases

Incident Port down after deploy. Confirm the process is listening on the expected port.
